## Windows BAS Simulation Toolkit

A Windows-based Breach and Attack Simulation (BAS) research project written in C, focused on reproducing selected MITRE ATT&CK techniques and validating their visibility through Windows security telemetry.

The project studies real-world adversary behavior, investigates the underlying Windows mechanisms, and implements controlled simulations using native Windows APIs.

### Objectives

- Understand and implement selected MITRE ATT&CK techniques.
- Study real-world adversary procedures and security research.
- Develop Windows simulation modules using C and native Windows APIs.
- Understand Windows internals and operating system behavior.
- Observe and analyze Windows security telemetry.

### Development Methodology

- Study the MITRE ATT&CK technique and its scope.
- Investigate documented real-world adversary procedures.
- Review relevant security research and technical references.
- Identify the Windows APIs and mechanisms involved.
- Implement a controlled simulation in C.
- Compile and execute in a Windows lab.
- Observe Windows security telemetry.
- Document execution results, detection opportunities and limitations.
